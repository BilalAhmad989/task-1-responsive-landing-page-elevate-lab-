c# Task 1: Responsive Landing Page (HTML & CSS)

Web Development Internship, Elevate Labs.

A clean, responsive landing page for **BrightPath Tutoring**, an online Science and English tutoring service.

## Files
- `index.html`: page structure using semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- `style.css`: all styling, layout and media queries

## What I built
- **Header** with a logo and navigation links
- **Hero section** with a heading, paragraph and call-to-action buttons
- **Subjects section** laid out with CSS Grid (3 columns, then 2, then 1)
- **Why Us section** laid out with Flexbox
- **Footer** with social links and copyright

## Responsive design
- Media queries at `900px` (tablet) and `700px` (mobile)
- On small screens the nav collapses into a hamburger menu (pure CSS, using a checkbox toggle, no JavaScript)
- Hero stacks vertically, grid columns reduce, footer centers

## Concepts practised
HTML5, CSS3, Flexbox, Grid, Media Queries, Responsive Design, CSS variables

## How to run
1. Open the folder in VS Code
2. Right-click `index.html` and choose **Open with Live Server**
3. Resize the browser window to test responsiveness

## Tools
VS Code, Chrome, Live Server extension
